# projeto-finanças

## Administrador

O perfil administrativo usa o email `admconfia@confia.com` e é criado
automaticamente no primeiro login com esse email. Configure a variável de
ambiente `CONFIA_ADMIN_PASSWORD` no servidor PHP com a senha inicial desejada.
O sistema armazena somente o hash dessa senha no banco. Apenas esse perfil pode
abrir a lista de usuários cadastrados.
